# CampusCycle MVP (校园二手交易平台)

这是一个基于“求购驱动”理念设计的校园二手交易最小可行性产品（MVP）。

## 核心痛点与解法
传统二手平台采用“卖家发布，买家搜索”的单向模式，导致校园内大量长尾物品（如特定教材）出现“想买却搜不到”的供需真空。
本项目反其道而行之，通过「求购广场」让买家主动发布需求，卖家反向搜索联系，实现“货找人”的双向撮合。

## MVP极简策略
为了快速验证业务假设，本产品进行了极致的战略取舍：
- **砍掉登录与实名认证**：降低用户使用门槛，冷启动优先。
- **砍掉站内 IM 与留言板**：通过“一键复制脱敏微信”的极轻量交互，直接引流至线下交易，极致降低开发成本。

## 技术实现
本项目由产品经理采用 **Vibe Coding (AI 辅助编程)** 独立完成开发与部署，基于原生 HTML/CSS/JS 编写。
